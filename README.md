# AevMotion

**AevMotion（エーブモーション）** は、スマートフォンやパソコンで使える、動画GIF変換・画像高解像度化ツールです。

動画から好きな場面を切り出してGIFアニメーションを作成したり、複数の画像をまとめて拡大したりできます。面倒な会員登録は不要です。

## できること

- 動画の好きな範囲を切り出してGIFに変換
- GIFのフレームレート・サイズ・再生速度・色数を調整
- GIFのプレビューと端末への保存
- 最大5枚の画像をまとめて高解像度化
- 画像を2倍・3倍・4倍に拡大
- PNG・JPG・WebP形式で画像を保存

## 使い方：動画をGIFに変換する

1. AevMotionを開き、「動画ファイルを選択」を押します。
2. 端末内に保存されている動画を選択します。スマートフォンの画面録画も、動画ファイルとして保存されていれば読み込めます。
3. 動画プレビューを確認し、開始時間と終了時間を設定します。スライダーまたは秒数の入力欄で調整できます。
4. GIFの設定を選びます。
   - **フレームレート（FPS）：** 数値を大きくすると動きが滑らかになりますが、ファイルサイズや処理負荷が増えます。
   - **GIF幅：** 画像の横幅です。大きくすると見やすくなりますが、ファイルサイズが増えます。
   - **再生速度：** GIFの再生速度を調整します。
   - **色数・画質：** 色数を増やすと色を細かく表現できますが、ファイルサイズが増える場合があります。
   - **ループ再生：** オンにするとGIFを繰り返し再生します。
5. 「GIFを作成する」を押して、変換が終わるまで待ちます。
6. 完成したGIFをプレビューで確認し、「GIFを保存」を押します。

## 使い方：画像を高解像度化する

1. 「画像を選択（最大5枚）」を押します。
2. 拡大したい画像を1枚から5枚まで選びます。
3. 拡大倍率を選択します（2倍・3倍・4倍）。
4. 保存形式を選びます。
   - **PNG：** 画質を保ちやすい形式です。
   - **JPG：** 写真などに適した形式です。
   - **WebP：** ファイルサイズを抑えやすい形式です。
5. 「選択した画像をまとめて高解像度化」を押します。
6. 処理が終わると画像ごとに結果が表示されます。「この画像を保存」から個別に保存できます。「新しいタブで開く」で拡大後の画像を確認することもできます。

画像は端末への負荷を抑えるため、1枚ずつ順番に処理されます。1枚あたりのファイルサイズは30MB以下、拡大後の画像は最大40メガピクセル、縦横それぞれ最大12,000ピクセルまでです。

## おすすめ設定

スマートフォンでGIFを作る場合は、まず次の設定から試してください。

- フレームレート：15 FPS
- GIF幅：480 px
- 色数・画質：192色
- 動画の範囲：必要な部分だけ短く切り出す

動作が重い場合や変換に失敗する場合は、動画の範囲を短くするか、GIF幅やFPSを小さくしてください。

## よくある質問・困ったときは

**Q. 動画を選択できません。**

A. 端末に保存されている動画ファイルを選択してください。動画の形式によっては読み込めない場合があります。

**Q. 変換エンジンの読み込みが終わりません。**

A. 初回のGIF変換時には変換エンジンのダウンロードが必要です。インターネット接続を確認し、ページを再読み込みしてからもう一度お試しください。

**Q. GIFの作成に失敗します。**

A. 動画が長すぎる、出力サイズが大きい、端末のメモリが不足しているなどの可能性があります。短い範囲を選び、GIF幅を320 pxまたは480 px、FPSを低めに設定してください。

**Q. 画像の高解像度化に失敗します。**

A. 画像が30MBを超えていないか、拡大後の画像が上限を超えていないか確認してください。一度に処理する画像の枚数を減らすことでも改善する場合があります。

**Q. 高解像度化で画像の細部も鮮明になりますか？**

A. AevMotionの画像拡大は高品質な補間処理です。画像のピクセル数を増やして拡大しますが、AIによって失われた細部を復元する機能ではありません。

**Q. スマートフォンでも使えますか？**

A. はい。スマートフォンのブラウザーから利用できます。端末の性能やメモリによって処理できる動画・画像の大きさは異なります。

## プライバシーについて

- GIF変換はブラウザー内で行われ、選択した動画がAevMotionのサーバーへアップロードされることはありません。
- 画像の高解像度化も端末内で処理されます。
- GIF変換エンジンの初回読み込みにはインターネット接続が必要です。
- AevMotion自体に画面録画機能はありません。画面録画を使う場合は、端末で録画・保存した動画ファイルを読み込んでください。

## ご利用上の注意

- 大きな動画や画像は、端末によって処理に時間がかかったり、正常に処理できなかったりする場合があります。
- GIFは元の動画よりファイルサイズが大きくなることがあります。
- 著作権や各サービスの利用規約を守り、利用する動画・画像をご自身で確認してください。
