AevMotion Android版 インストールパッケージ

【内容】
- AevMotion.apk：AevMotionアプリ本体
- 利用規約.txt：利用条件と注意事項
- 使い方ガイド.txt：インストール方法と基本操作

【インストール手順】
1. ZIPファイルを端末にダウンロードします。
2. Androidの「Files」などのファイル管理アプリでZIPを開きます。
3. ZIPの中身を端末のフォルダーへ展開（解凍）します。
4. AevMotion.apk をタップします。
5. Androidが表示するアプリ名・提供元・権限などを確認します。
6. Androidの標準画面に従ってインストールします。

【重要】
- このZIPはAndroidのインストール制限や保護者による管理を解除するものではありません。
- Androidや端末の管理者によってインストールが制限されている場合は、管理者に確認してください。
- インストール画面で警告が出た場合は、内容を確認し、不明な場合はインストールを中止してください。
- AevMotionはインターネットから更新されたAPKを取得する機能を持ちません。最新版は公式GitHub Releaseから取得してください。
